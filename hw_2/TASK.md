# Практика к уроку 3

Повторите задачу с созданием заказов и добавьте к ней тесты.

## Задачи

- Напишите функцию создания заказа. Неположительный ID должен возвращать ошибку.
- Напишите функцию добавления позиции в заказ, которая возвращает error в случае
  некорректных данных. Обработайте nil, пустое имя и отрицательную цену. Функция
  должна менять переданный заказ.
- Напишите функцию, которая считает сумму позиций.
- Создайте `map[string]string` с человекочитаемыми названиями статусов.
- Поставьте breakpoint в `AddItem` и проследите, как меняются `len` и `cap` среза.

## Проверочные сценарии

- валидный заказ без позиций имеет сумму 0;
- после добавления двух позиций сумма равна их сумме;
- функция добавления позиции возвращает ошибку и не паникует;
- изменение копии `Order` не меняет исходную структуру;
- запись в заранее не созданную map должна быть исправлена через `make`.
